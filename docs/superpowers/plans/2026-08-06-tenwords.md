# TenWords Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local service + Chrome extension + webapp that compresses any webpage or document so every paragraph becomes exactly 10 plain words, plus a 10-word TL;DR.

**Architecture:** An Express service on localhost:4710 is the only component that talks to the Anthropic API (Haiku 4.5, one batched call per document, server-side exactly-10-words enforcement). A Chrome MV3 extension rewrites pages in place; a static webapp served by the service handles URLs and PDF/docx/txt files. Spec: `docs/superpowers/specs/2026-08-06-tenwords-design.md`.

**Tech Stack:** Node.js (ESM, `node --test` for tests), Express, `@anthropic-ai/sdk`, `@mozilla/readability` + `jsdom`, `pdf-parse`, `mammoth`, `multer`, Chrome Manifest V3.

## Global Constraints

- Model: `claude-haiku-4-5-20251001`, one batched call per document; one corrective retry call max.
- Every returned summary and the TL;DR must be exactly 10 words — enforced in code, never trusted from the model.
- Word definition: tokens separated by whitespace; hyphenated words count as one.
- Blocks eligible for summarizing: ≥ 16 words. Shorter paragraphs and headings are never summarized.
- Secrets: `ANTHROPIC_API_KEY` in `.env` only; `.env` gitignored; `.env.example` has a placeholder.
- Fail loudly: service exits non-zero on missing key/port conflict; `unhandledRejection` handler that exits; no swallowed errors; API failures return structured `{error}` JSON.
- No test framework dependency — use Node's built-in `node --test`.
- Service port: 4710 (override with `PORT`).

```js
export function countWords(text) {
  return text.trim().split(/\s+/).filter(Boolean).length
}

export function fixToTen(summary, originalText) {
  const words = summary.trim().split(/\s+/).filter(Boolean)
  if (words.length >= 10) return words.slice(0, 10).join(' ')
  const pool = originalText.trim().split(/\s+/).filter(Boolean)
  return words.concat(pool.slice(0, 10 - words.length)).join(' ')
}

export function parseJson(text) {
  const start = text.indexOf('{')
  const end = text.lastIndexOf('}')
  if (start === -1 || end <= start) throw new Error('no JSON object in model output')
  return JSON.parse(text.slice(start, end + 1))
}
```

- [ ] **Step 3: Implement `service/summarizer.js`**

```js
import { countWords, fixToTen, parseJson } from './words.js'

export const MODEL = 'claude-haiku-4-5-20251001'

const RULES = `Rules:
- EXACTLY 10 words per summary. Count them. Not 9, not 11.
- Use plain, everyday vocabulary. No jargon, no fancy words.
- Keep the main point. Drop filler, hedging, and repetition.
- A word is anything separated by spaces; hyphenated words count as one.
- Respond with ONLY the JSON object, no other text.`

function firstText(response) {
  return response.content?.[0]?.text ?? ''
}

async function call(client, prompt) {
  const response = await client.messages.create({
    model: MODEL,
    max_tokens: 8192,
    messages: [{ role: 'user', content: prompt }],
  })
  return parseJson(firstText(response))
}

export async function summarizeBlocks(blocks, client) {
  const prompt = `You compress verbose text into plain language.

Below are text blocks from one document. For EACH block, write a summary of EXACTLY 10 words. Also write "tldr": EXACTLY 10 words summarizing the whole document.

${RULES}

JSON shape: {"tldr": "...", "summaries": [{"id": "...", "text": "..."}]}

Blocks:
${JSON.stringify(blocks)}`

  const first = await call(client, prompt)
  let tldr = typeof first.tldr === 'string' ? first.tldr : ''
  const byId = new Map(
    (Array.isArray(first.summaries) ? first.summaries : [])
      .filter(s => s && typeof s.id === 'string' && typeof s.text === 'string')
      .map(s => [s.id, s.text]),
  )

  const offenders = blocks.filter(b => countWords(byId.get(b.id) ?? '') !== 10)
  const tldrWrong = countWords(tldr) !== 10

  if (offenders.length > 0 || tldrWrong) {
    const retryPrompt = `These summaries had the wrong word count. Rewrite EACH to EXACTLY 10 words.

${RULES}

JSON shape: {${tldrWrong ? '"tldr": "...", ' : ''}"summaries": [{"id": "...", "text": "..."}]}
${tldrWrong ? '\nAlso rewrite "tldr" (a 10-word summary of the whole document).\n' : ''}
Blocks to redo:
${JSON.stringify(offenders)}`
    try {
      const retry = await call(client, retryPrompt)
      for (const s of Array.isArray(retry.summaries) ? retry.summaries : []) {
        if (s && typeof s.id === 'string' && typeof s.text === 'string') byId.set(s.id, s.text)
      }
      if (tldrWrong && typeof retry.tldr === 'string') tldr = retry.tldr
    } catch {
      // fall through to deterministic fix below
    }
  }

  const allOriginal = blocks.map(b => b.text).join(' ')
  if (countWords(tldr) !== 10) tldr = fixToTen(tldr, allOriginal)

  const summaries = blocks.map(b => {
    let text = byId.get(b.id) ?? ''
    if (countWords(text) !== 10) text = fixToTen(text, b.text)
    return { id: b.id, text }
  })

  return { tldr, summaries }
}
```

Note: the "garbage twice" test passes because the first `call` throws from `parseJson` and that rejection propagates (the try/catch only wraps the retry call).

import 'dotenv/config'
import path from 'node:path'
import { fileURLToPath } from 'node:url'
import express from 'express'
import Anthropic from '@anthropic-ai/sdk'
import { summarizeBlocks } from './summarizer.js'

const HERE = path.dirname(fileURLToPath(import.meta.url))

export function createApp(client) {
  const app = express()
  app.use(express.json({ limit: '5mb' }))
  app.use(express.static(path.join(HERE, '..', 'webapp')))

  app.post('/summarize', async (req, res) => {
    const blocks = req.body?.blocks
    if (!Array.isArray(blocks) || blocks.length === 0 ||
        !blocks.every(b => b && typeof b.id === 'string' && typeof b.text === 'string')) {
      return res.status(400).json({ error: 'blocks must be a non-empty array of {id, text}' })
    }
    try {
      res.json(await summarizeBlocks(blocks, client))
    } catch (err) {
      console.error('summarize failed:', err)
      res.status(502).json({ error: `summarization failed: ${err.message}` })
    }
  })

  return app
}

const isMain = process.argv[1] && path.resolve(process.argv[1]) === fileURLToPath(import.meta.url)
if (isMain) {
  process.on('unhandledRejection', (reason) => {
    console.error('Unhandled Rejection:', reason)
    process.exit(1)
  })
  if (!process.env.ANTHROPIC_API_KEY) {
    console.error('ANTHROPIC_API_KEY missing. Copy .env.example to .env and set it.')
    process.exit(1)
  }
  const port = Number(process.env.PORT) || 4710
  const server = createApp(new Anthropic()).listen(port, () => {
    console.log(`TenWords service running on http://localhost:${port}`)
  })
  server.on('error', (err) => {
    console.error(`Failed to start on port ${port}: ${err.message}`)
    process.exit(1)
  })
}
```

import { Readability } from '@mozilla/readability'
import { JSDOM } from 'jsdom'
import mammoth from 'mammoth'
import pdfParse from 'pdf-parse/lib/pdf-parse.js'
import { countWords } from './words.js'

// pdf-parse is imported via its inner module: the package entry point runs
// debug code when it can't detect a parent module, which crashes under ESM.

export function toBlocks(paragraphs) {
  return paragraphs
    .map(p => p.trim())
    .filter(p => countWords(p) >= 16)
    .map((text, i) => ({ id: `p${i}`, text }))
}

export function paragraphsFromHtml(html, url) {
  const dom = new JSDOM(html, { url })
  const article = new Readability(dom.window.document).parse()
  if (!article?.content) throw new Error('could not extract an article from this page')
  const articleDom = new JSDOM(article.content)
  return [...articleDom.window.document.querySelectorAll('p')].map(p => p.textContent)
}

export function paragraphsFromText(text) {
  return text.split(/\r?\n\s*\r?\n/).map(p => p.replace(/\s+/g, ' ').trim()).filter(Boolean)
}

export async function extractUrl(url, fetchImpl = fetch) {
  const res = await fetchImpl(url, { headers: { 'User-Agent': 'Mozilla/5.0 (TenWords local reader)' } })
  if (!res.ok) throw new Error(`fetch failed with status ${res.status}`)
  return toBlocks(paragraphsFromHtml(await res.text(), url))
}

export async function extractFile(buffer, filename) {
  const ext = filename.toLowerCase().split('.').pop()
  if (ext === 'txt') return toBlocks(paragraphsFromText(buffer.toString('utf8')))
  if (ext === 'pdf') {
    const { text } = await pdfParse(buffer)
    return toBlocks(paragraphsFromText(text))
  }
  if (ext === 'docx') {
    const { value } = await mammoth.extractRawText({ buffer })
    return toBlocks(paragraphsFromText(value))
  }
  throw new Error(`unsupported file type: .${ext} (use pdf, docx, or txt)`)
}
```

  const st = (window.__tenwords ??= { active: false, busy: false, originals: new Map(), banner: null })
  if (st.busy) return
  if (st.active) return restore()

  function countWords(t) {
    return t.trim().split(/\s+/).filter(Boolean).length
  }

  function container() {
    return document.querySelector('article') || document.querySelector('main') || document.body
  }

  function candidates() {
    return [...container().querySelectorAll('p')].filter(p => countWords(p.textContent) >= 16)
  }

  async function condense() {
    const els = candidates()
    if (els.length === 0) return toast('TenWords: no long paragraphs found on this page')

    toast('TenWords: condensing…', 60000)
    const blocks = els.map((el, i) => ({ id: `p${i}`, text: el.textContent.trim() }))
    const resp = await chrome.runtime.sendMessage({ type: 'summarize', blocks })
    clearToast()
    if (!resp?.ok) {
      return toast(`TenWords: ${resp?.error || 'no response'} — start the service with launch.cmd`)
    }

    const byId = new Map(resp.data.summaries.map(s => [s.id, s.text]))
    els.forEach((el, i) => {
      const summary = byId.get(`p${i}`)
      if (!summary) return
      st.originals.set(el, { html: el.innerHTML, style: el.getAttribute('style') })

      el.style.lineHeight = '1.9'
      el.style.marginTop = '1.6em'
      el.style.marginBottom = '1.6em'

    banner(resp.data.tldr)

# TenWords

Every paragraph becomes exactly ten words. A local service + Chrome
extension + web page that condense verbose text (webpages, PDFs, docx,
txt) into 10-word-per-paragraph summaries with a 10-word TL;DR.

## Setup

1. `npm install`
2. Copy `.env.example` to `.env` and set `ANTHROPIC_API_KEY`.
3. `launch.cmd` (or `npm start`) — service runs on http://localhost:4710

## Use it

**On any webpage:** load `extension/` unpacked via `chrome://extensions`
(Developer mode → Load unpacked). Then click the TenWords icon or press
**Alt+T** on any article. Press again (or "restore original") to undo.

**On documents and URLs:** open http://localhost:4710 — paste a URL or
drop a PDF/docx/txt.

## How it works

Surfaces send paragraph blocks to `POST /summarize`; the service makes
one batched Haiku call, counts every summary's words, retries offenders
once, and deterministically fixes anything still wrong — you never see
a line that isn't exactly ten words. `POST /extract` turns URLs
(Readability) and files (pdf-parse / mammoth) into blocks.

## API

`POST /summarize` — `{"blocks":[{"id":"p0","text":"..."}]}` →
`{"tldr":"...","summaries":[{"id":"p0","text":"..."}]}`

`POST /extract` — multipart `file` (pdf/docx/txt) or `{"url":"..."}` →
`{"blocks":[{"id":"p0","text":"..."}]}`

- `npm test` — full suite (no API key needed; Anthropic client is mocked)
