# TenWords marketing assets

Generated 2026-08-09 by the marketing studio (direction: "Galley Proof" —
the film as a printed page being set; signature move: THE FOLD). Source
projects and render pipeline live in the animations engine repo; per-platform
paste-ready kits (right-aspect video, caption, alt text, thumbnail, POST.md)
are in the engine's `out/tenwords/postkit/`.

| File | Use |
|---|---|
| `launch.mp4` | Hero launch video, 75.6s, 16:9, mastered -14 LUFS. Site, YouTube, X pinned post. |
| `product-demo.mp4` | Raw-capture demo with camera/captions, 57s. Long-form embeds, docs. |
| `logo-reveal.mp4` | 5s pilcrow draw-on. Intro sting, loops before talks. |
| `social-x.mp4` | 10s X clip, story hook, sound-off legible. |
| `social-linkedin.mp4` | 10s LinkedIn clip, stat hook, sound-off legible. |
| `og.png` | Link-preview card 1200x630 (also deployed at tenwords.io/og.png). |
| `og.mp4` / `og.gif` | Animated link/social card loop. |
| `readme.gif` | The fold, payoff-first, 2.8MB. Embedded in the repo README. |
| `thumbs/` | Poster frames per aspect (completed-fold moment, frame 290). |
| `captions/launch.srt` `.vtt` | Voiceover caption sidecars for YouTube/LinkedIn uploads. |

Large `.mp4` files are kept out of git (see `.gitignore`); statics and the
README gif are committed. Aspect variants (9:16, 1:1, 4:5, captioned) are in
the engine repo's `out/tenwords/matrix/`.
